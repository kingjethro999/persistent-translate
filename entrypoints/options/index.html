Pause a saved rule across its tabs or remove the choice. Removing a rule leaves the browser permission in place; revoke it in the browser’s extension settings.

Your privacy

This version uses Chrome’s on-device Translator API. It has no cloud provider, analytics, accounts, or persistent page-text cache. It stores website origins, language choices and enabled states in local extension storage.

Chrome may download language packs through its own infrastructure after you prepare a pair. The engine tab must remain open. Firefox currently has no configured translation engine.

Only eligible top-frame text nodes are translated. Input values, passwords, editable regions and code are skipped. Frames, closed shadow roots, images and PDFs are outside this preview’s coverage.

Permissions: storage saves choices; activeTab and scripting enable actions you invoke; optional site access lets saved choices apply on later documents. No website access is granted at installation.

Incognito is disabled by default. Do not enable it for this preview; separate private-session behavior has not been verified.
